# Magic Nails

Første version af Magic Nails-hjemmesiden.

## Indeholder
- Sort/guld Magic Nails-design
- Home
- About Us
- Frit valg
- Gallery
- Contact
- Booking-demo
- Mobilvenligt layout
- Magic Nails-logo og favicon

## Vigtigt
Booking og kontaktformular er demo-funktioner uden backend. De reserverer ikke en rigtig tid og sender ikke e-mail endnu.

## Senere
- Tilføj endelig adresse, telefon og e-mail
- Tilslut rigtigt bookingsystem/database
- Tilslut MobilePay via en godkendt betalingsudbyder
- Tilføj eventuelt kundelogin og notifikationer
